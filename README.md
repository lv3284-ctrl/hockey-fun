# ICEBOUND

A fast, immersive arcade hockey game that runs right in your browser. Skate into the zone, sprint to open ice, deke the goalie, and put the puck in the net before the final horn.

## Play

Open `index.html` in a modern browser. No build step or dependencies required.

- **WASD / arrow keys** — skate
- **Space** — shoot (or pick up a nearby loose puck)
- **Shift** — sprint (uses energy; energy refills while skating normally)
- **P** — pass to your winger
- **Esc** — pause / resume
- **♫** — toggle sound

On touch screens, use the on-screen skate pad and action buttons. The game includes rival skaters, a goalie, puck physics, hits, a ticking clock, a scoreboard, crowd/ice effects, and sudden-death overtime.
